# Fur & Fin App Prototype

This folder is completely separate from the live website files.

The current website stays untouched.
If you do not want this app idea later, you can simply delete this folder and your current site remains exactly as it is.

## Goal

Build a future Fur & Fin app without changing the current website first.

## Best path

1. Keep the website live as it is now.
2. Use the website as inspiration and content base.
3. Plan the app structure separately.
4. Later decide whether to build:
   - a PWA
   - a simple mobile app wrapper
   - a full custom app

## Recommended first version

A simple mobile app with these sections:

- Home
- About
- Hunting Seasons
- Videos
- Gear
- Field Notes
- Questions & Tips
- Contact

## Features for version 1

- clean mobile home screen
- direct links to YouTube and Instagram
- hunting seasons section
- videos section
- gear overview
- field notes / story section
- contact page

## Features for later

- photo uploads
- own hunting diary
- own fishing diary
- trip log
- map pins
- weather
- push notifications
- login / profile
