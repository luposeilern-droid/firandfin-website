# Fur & Fin App Roadmap

## Phase 1

Keep the current website online and unchanged.

## Phase 2

Create a simple app concept with:

- app icon
- splash screen
- mobile navigation
- home screen
- seasons screen
- videos screen
- contact screen

## Phase 3

Choose one build direction:

### Option A

PWA

Good because:

- fastest
- cheapest
- based on the current website

### Option B

Wrapped mobile app

Good because:

- can go into app stores
- keeps the website style
- easier than a full rebuild

### Option C

Full custom app

Good because:

- best long-term
- strongest features
- full control

## My recommendation

Start with Option A or B first.

## What the app should feel like

- simple
- clean
- outdoors
- strong photography
- easy to use on phone
- fast access to videos and seasons
