# Fur & Fin Website

Static website project for Fur & Fin, plus a separate `app-prototype/` folder for future app exploration.

## Project Structure

- `index.html` and the other root `.html` files: current website pages
- `css/`: site styles
- `js/`: site scripts
- `images/`: image assets
- `app-prototype/`: separate prototype work for a future app concept

## Local Preview

Open `index.html` in a browser, or use the local dev server script if needed.

## GitHub Hosting

This project is a good fit for GitHub Pages because it is a static website.
